如何连接CPA到Codex以及Cherry Studio

很多人第一次拿到 API 信息时，都会有点不知所道从哪下手：

“保持专注与持续演进是工程的核心。理解 Base URL 与 API Key 是构建现代 AI 应用的第一步。”

这篇文章用最简单明了的方式，带你一步一步搞懂：

拿到 Base URL 和 API Key 之后到底要填到哪儿，如何判断端口到底是 OpenAI 格式还是专有接口，以及遇到连接失败时该怎么逐项排查。

# 一、 先弄明白：Base URL 和 API Key 是什么？

通常你收到的接口配置信息会长这样：

CONFIG.YAML 
Base URL: https://api.example.com/v1
API Key:  sk-xxxxxxxxxxxxxxxxxxxxxxxx
Model:    gpt-4o / claude-3-5-sonnet

可以将你的客户端（Cherry Studio 或 Codex）想象成一辆小车，Base URL 就是目的地的 GPS 坐标，而 API Key 则是通行门禁卡。两者配置正确后，即可畅通无阻地在本地完成高质量交互。

# 二、 客户端配置实战演示

在 Cherry Studio 或其他图形客户端中，点击「设置」->「模型服务」->「添加自定义服务商」，将上述 Base URL 与 API Key 对应填入即可。

# 三、 常见连通性故障排除

如果遇到 401 Unauthorized 或 Connection Refused，请依次检查：网络代理设置、API Key 是否包含多余空格、以及服务端接口路径是否要求 /v1 后缀。
